# 定时鼠标移动

一个 Chrome 扩展。启动后，按设定间隔在选中的网页内平滑地轻移鼠标。每次只对一个标签页生效，移动时不会点击或滚动页面。

## 安装

需要 Chrome 118 或更新版本。

1. 在仓库页面点击 **Code → Download ZIP**，下载并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择解压后包含 `manifest.json` 的文件夹。

## 使用

1. 打开目标网页，等页面加载完成。
2. 点击 Chrome 工具栏里的扩展图标，打开 **定时鼠标移动**。
3. 设置移动间隔，点击 **在此标签页启动**。默认每 3 分钟一次，可设为 1–60 分钟。第一次移动会在设定的间隔后执行。
4. 要结束运行，打开扩展并点击 **停止**。刷新、换页或关闭目标标签页也会自动停止。

切换到其他标签页时，移动仍只发给启动时选中的网页。扩展弹窗会显示下一次移动时间。

## Chrome 调试提示

扩展通过 Chrome 调试接口向目标网页发送鼠标移动事件。运行时，Chrome 会显示调试提示。通过该提示取消调试也会停止扩展。
