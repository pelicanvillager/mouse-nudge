# 定时鼠标移动

一个 Chrome 扩展。启动后，按设定间隔向选中的网页发送鼠标移动事件。每次只对一个标签页生效，轨迹和时间也只显示在该页。

## 安装

需要 Chrome 118 或更新版本。

1. 在仓库页面点击 **Code → Download ZIP**，下载并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择解压后包含 `manifest.json` 的文件夹。

## 使用

1. 打开目标网页，等页面加载完成后，在 Chrome 工具栏打开 **定时鼠标移动**。
2. 设置移动间隔。默认每 3 分钟一次，可设为 1–60 分钟。
3. 点击 **框选范围并启动**，在网页上拖出矩形，松开鼠标即启动。也可以点击 **用默认范围启动**，使用网页中央区域。
4. 到达设定间隔后，网页会显示蓝色轨迹及「上次移动」时间。每次移动都会更新标记。
5. 在目标页打开扩展并点击 **停止**，可以结束运行并清除标记。刷新、换页或关闭目标标签页也会停止。

切换到其他标签页时，扩展仍只向原目标页发送移动事件。在其他标签页操作鼠标不会改变目标页的移动范围或轨迹。

## 网页兼容性

扩展在目标网页内发送 JavaScript 模拟事件，系统光标不会移动，Chrome 也无需开启调试会话。只接受可信鼠标输入的网页可能会忽略这些事件。
